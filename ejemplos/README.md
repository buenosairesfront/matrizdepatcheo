# Ejemplos

Los 12 patches de fábrica como archivos `.json`. Para usarlos: en la app, **Patches → Abrir archivo** y elegí uno. Quedan guardados en *Mis patcheos*.

También sirven de punto de partida para escribir patches a mano; el formato está en [`../docs/FORMATO-PATCH.md`](../docs/FORMATO-PATCH.md).
